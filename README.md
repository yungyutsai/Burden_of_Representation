# Racially Divergent Patterns in the Relationship between Same-Race Subordinates and Federal Supervisors’ Job Satisfaction

This repository contains datasets and code for the paper titled "Racially Divergent Patterns in the Relationship between Same-Race Subordinates and Federal Supervisors’ Job Satisfaction." 

The paper is available at: https://journals.sagepub.com/doi/10.1177/00910260261444392

# Data Availability

This paper uses data from three sources:

1. Federal Employee Viewpoint Survey (FEVS) Data: https://www.opm.gov/fevs/public-data-file/ (OPM has rescinded the public dataset in 2026)
2. Fedscope Online Diversity Cube (OPM has taken down the data in 2025)
3. Federal Employment Raw Data: https://data.opm.gov/get-data/data-downloads

This repository contains the main dataset for producing tables and figures. Due to the data size limit, the file in the folder "wdata" has been compressed into a zip file. Please unzip it before running the code.

# Code Availability

The codes (Stata do files) of data construction and analysis are available at this repository.
