# The Relationship between Same-Race Subordinates and Federal Supervisors’ Job Satisfaction

This repository contains datasets and codes for the paper titled "The Relationship between Same-Race Subordinates and Federal Supervisors’ Job Satisfaction." 

Due to the data size limit, the file in the folder "wdata" has been compressed into a zip file. Please unzip it before running the code.
